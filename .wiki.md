# Project Summary
The project, **mehmetkuru.dev**, is a boutique web and mobile development agency that delivers tailored software solutions and digital marketing services to small businesses, startups, and entrepreneurs. The agency specializes in consulting, product design, custom software development, digital marketing, and DevOps services. The website features a modern design with a user-friendly interface, showcasing services, portfolio, blog, and contact information, while supporting multiple languages (English, Turkish, German). Recent enhancements include a new Google Ads campaign, improved site performance with Google Analytics 4 (GA4) tracking, and a refreshed branding strategy. Additionally, SEO-optimized content has been created to enhance online visibility.

# Project Module Description
- **Frontend**: Developed with React, offering a dynamic interface, effective routing, state management, and multi-language support.
- **Backend**: Powered by Atoms Cloud for authentication and database management for projects, blog posts, and inquiries.
- **Hero Banner**: Features a visually appealing cyberpunk workspace image.
- **Admin Panel**: Facilitates CRUD operations for projects and blog posts, along with inquiry management.
- **Services Page**: Showcases core services with integrated pricing options and introductory content.
- **Analytics Integration**: GA4 tracking implemented for monitoring user interactions.
- **WhatsApp Floating Button**: A floating button on all pages links to the updated contact number.
- **Performance Optimizations**: Enhanced loading speeds through image optimization, lazy loading, and code splitting.
- **Branding Updates**: Updated logo and removed "By Mehmet KURU Dev" text, with the WhatsApp button featuring the original icon.
- **SEO Content**: Newly created SEO-optimized articles to improve search engine visibility.

# File Description Inventory
- **app/backend/main.py**: Entry point for the backend application.
- **app/backend/core/**: Contains core functionalities like authentication and database connections.
- **app/backend/models/**: Defines data structures for various entities like projects and blog posts.
- **app/backend/routers/**: API endpoints for handling requests related to projects, blog posts, and inquiries.
- **app/backend/services/**: Business logic and interaction with the database.
- **app/frontend/src/**: Contains all frontend source code including components, pages, and styles.
- **app/frontend/public/**: Static assets such as images and the favicon.
- **app/frontend/package.json**: Lists project dependencies for the frontend.
- **app/frontend/src/pages/Services.tsx**: Displays core service offerings with integrated pricing options and about content.
- **app/frontend/src/pages/Portfolio.tsx**: Displays projects categorized into SaaS, E-commerce, Websites, and Mobile Applications with a timeline feature.
- **app/frontend/src/components/InstagramCarousel.tsx**: Updated to link to portfolio categories instead of Instagram API.
- **app/frontend/src/components/Layout.tsx**: Updated to include a floating WhatsApp button linking to the new contact number and to remove branding text.
- **app/frontend/src/pages/Index.tsx**: Updated to include the new hero banner.
- **app/frontend/src/index.css**: Updated styles to match the new color scheme.
- **app/frontend/site.config.json**: Contains the Google Analytics 4 measurement ID for tracking.
- **app/frontend/index.html**: Main HTML file where the GA4 tracking script is integrated.
- **app/frontend/seo/content/**: Contains newly created SEO articles to enhance online visibility.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: Python, FastAPI, Atoms Cloud
- **Database**: PostgreSQL
- **Deployment**: Cloud services for hosting

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
2. **Build the Project**:
   - Run the build command:
     ```
     pnpm run build
     ```
3. **Run the Application**:
   - Start the backend server and frontend development server as per the setup instructions in their respective README files.
