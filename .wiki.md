# Project Summary
The project, **mehmetkuru.dev**, serves as a professional portfolio and agency website that presents software development and digital marketing services. It showcases the founder's expertise and the agency's offerings, including custom software development, digital marketing, and product design. The site features an engaging 3D hero animation, intuitive navigation, and dedicated sections for services, portfolio, blog, and contact, aimed at attracting and retaining clients. The website supports multiple languages (English, Turkish, and German) and integrates service pricing options directly into the services section. Recently, Google Analytics 4 (GA4) tracking has been integrated to enhance marketing insights.

# Project Module Description
- **Frontend**: Built with React, providing a dynamic user interface, routing, state management, and multi-language support.
- **Backend**: Utilizes Atoms Cloud for authentication and database management of projects, blog posts, and inquiries.
- **3D Hero Animation**: Employs Three.js for an interactive visual experience on the homepage.
- **Admin Panel**: Supports CRUD operations for projects and blog posts and managing inquiries.
- **Services Page**: Displays core service offerings, including integrated pricing options, and now includes about content at the top.
- **Analytics Integration**: Google Analytics 4 tracking has been added to monitor user interactions.

# File Description Inventory
- **app/backend/main.py**: Entry point for the backend application.
- **app/backend/core/**: Contains core functionalities like authentication and database connections.
- **app/backend/models/**: Defines data structures for various entities like projects and blog posts.
- **app/backend/routers/**: API endpoints for handling requests related to projects, blog posts, and inquiries.
- **app/backend/services/**: Business logic and interaction with the database.
- **app/frontend/src/**: Contains all frontend source code including components, pages, and styles.
- **app/frontend/public/**: Static assets such as images and the favicon.
- **app/frontend/package.json**: Lists project dependencies for the frontend.
- **app/frontend/src/pages/Services.tsx**: Displays core service offerings with integrated pricing options and about content.
- **app/frontend/src/pages/Portfolio.tsx**: Displays projects categorized into SaaS, E-commerce, Websites, and Mobile Applications.
- **app/frontend/src/components/InstagramCarousel.tsx**: New component for displaying an Instagram carousel on all pages.
- **app/frontend/site.config.json**: Contains the Google Analytics 4 measurement ID for tracking.
- **app/frontend/index.html**: Main HTML file where the GA4 tracking script is integrated.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Three.js, i18next
- **Backend**: Python, FastAPI, Atoms Cloud
- **Database**: PostgreSQL
- **Deployment**: Cloud services for hosting

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
2. **Build the Project**:
   - Run the build command:
     ```
     pnpm run build
     ```
3. **Run the Application**:
   - Start the backend server and frontend development server as per the setup instructions in their respective README files.
