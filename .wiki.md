# Project Summary
**mehmetkuru.dev**, küçük işletmeler, girişimler ve girişimciler için web geliştirme, e-ticaret, SaaS, mobil uygulama, dijital pazarlama ve DevOps hizmetleri sunan çok dilli dijital ajans platformudur. Hizmetleri, portföyü, blog içeriklerini ve iletişim kanallarını sergiler; müşteri ve yönetici operasyonlarını tek panelde birleştirir.

Platform; kimlik doğrulama, rol bazlı paneller, proje takibi, faturalandırma, destek talepleri, dinamik site ayarları ve analitik görünüm sunar. Türkçe, İngilizce, Almanca, Arapça, Rusça, Çince ve Hintçe dillerini destekler. Arapça için RTL düzeni ve dil bazlı site ayarları bulunur.

Son güncellemeyle ana sayfa performansı ve PageSpeed skorları iyileştirilmiştir. Hero görseli responsive WebP varyantlarına dönüştürülmüş, kullanılmayan Three.js/Hero3D kaldırılmış, çeviri paketleri ve analitik grafikleri lazy-load edilmiştir. Ana JavaScript paketi 659,9 KB’tan 513,8 KB’a, statik varlıklar yaklaşık 5 MB’tan 201 KB’a düşürülmüştür.

# Project Module Description
- **Kimlik Doğrulama ve Roller**: Giriş, kayıt, oturum kapatma ve role göre panel yönlendirmesi.
- **Müşteri Paneli**: Projeler, ilerleme durumu, faturalar, ödemeler, destek talepleri ve profil bilgileri.
- **Yönetici Paneli**: Site ayarları, portföy, blog, müşteriler, faturalar, destek talepleri ve iletişim mesajları.
- **Site Ayarları**: Logo, iletişim bilgileri, sosyal bağlantılar, hero metinleri, fiyatlar, SEO bilgileri ve GA4 kimliği.
- **Dil Bazlı İçerik Yönetimi**: Hero, adres ve SEO alanları her dil için ayrı düzenlenebilir; eksik değerler varsayılan dile düşer.
- **Çoklu Dil ve RTL**: Yedi dil, bayraklı dil seçici, dinamik HTML `lang`/`dir` değerleri ve Arapça RTL desteği.
- **Lazy-Loaded Çeviriler**: Başlangıçta yalnızca Türkçe çeviri yüklenir; diğer diller ihtiyaç halinde indirilir.
- **Portföy Yönetimi**: Proje CRUD işlemleri, kategori, müşteri, teknoloji, durum ve ilerleme takibi.
- **Blog Yönetimi**: Blog CRUD işlemleri, kategori, içerik, kapak görseli, yayın durumu ve slug yönetimi.
- **Faturalandırma**: Yönetici fatura yönetimi; müşterilerin kendi faturalarını görüntülemesi.
- **Destek Talepleri**: Müşteri talepleri, yönetici yanıtları ve durum güncelleme.
- **Analitik Dashboard**: Trafik, SEO, reklam ve sosyal medya metrikleri; grafik kütüphanesi yalnızca ilgili yönetim sekmesinde yüklenir.
- **Dinamik Frontend**: Ana sayfa, hizmetler, iletişim, header, footer ve WhatsApp bağlantıları ayarlara bağlıdır.
- **Blog ve SEO**: Veritabanı yazıları ile statik Markdown makaleleri birlikte sunulur.
- **SEO ve Yapısal Veri**: Canonical, Open Graph, Twitter kartları, hreflang ve ProfessionalService JSON-LD desteği.
- **Performans Optimizasyonu**: Responsive WebP hero görselleri, preload, `srcset`, `sizes`, lazy loading, async decoding ve render-blocking azaltımı.
- **Erişilebilirlik ve UX**: `prefers-reduced-motion`, `:focus-visible`, açıklayıcı alt metinler ve etiketli sosyal bağlantılar.
- **Analytics Geciktirme**: GA4, ilk etkileşimden veya tarayıcı boşta kaldıktan sonra yüklenir.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, React Router
- **UI ve Grafikler**: Lucide React, Recharts, Sonner, Markdown-to-JSX
- **State/Data**: TanStack Query, React hooks, localStorage cache
- **Çoklu Dil**: i18next, react-i18next, JSON çeviri kaynakları ve dynamic import
- **Backend**: Python, FastAPI, web SDK
- **Kimlik Doğrulama**: Atoms Cloud Auth
- **Veritabanı**: PostgreSQL
- **Migration**: Alembic
- **Performans**: WebP, responsive images, preload, lazy loading, Vite manual chunks
- **Analitik**: GA4 ve backend analitik snapshot modeli
- **SEO**: Canonical, Open Graph, Twitter Cards, hreflang ve JSON-LD
- **Dağıtım**: Cloud hosting altyapısı

# Usage
1. Frontend dizinine geçin:
   ```bash
   cd app/frontend
   ```
2. Frontend bağımlılıklarını yükleyin:
   ```bash
   pnpm install
   ```
3. Lint kontrolünü çalıştırın:
   ```bash
   pnpm run lint
   ```
4. Production build alın:
   ```bash
   pnpm run build
   ```
5. Backend bağımlılıklarını kurun:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
6. Backend migration’larını uygulayın ve backend’i proje kurulumundaki sunucu komutuyla başlatın.
7. Frontend geliştirme sunucusunu veya production çıktısını deployment yapılandırmasına göre çalıştırın.
8. Yönetici erişimi için `site_settings` içindeki `admin_emails` değerine yetkili adresleri ekleyin.
9. Dil bazlı içerikleri **Site Ayarları > İçerik Dili** bölümünden düzenleyin.
10. Canlı Google Ads, Search Console veya sosyal medya verileri için ilgili API anahtarlarını ve OAuth bağlantılarını yapılandırın.
11. Yayın sonrası PageSpeed ölçümlerinde TTFB, CDN, Brotli/Gzip ve cache header değerlerini ayrıca kontrol edin.
12. Değişiklikleri doğrulamak için lint ve production build komutlarını çalıştırın.
