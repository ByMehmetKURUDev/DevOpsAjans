# Project Summary
The project aims to develop a comprehensive professional portfolio and agency website for mehmetkuru.dev, showcasing services and projects offered by By Mehmet KURU Dev. The website will feature a modern design with 3D elements, user authentication, and management panels for both clients and administrators.

# Project Module Description
- **Homepage**: A visually striking landing page with a 3D animated hero section.
- **About**: Information about the services and background of By Mehmet KURU Dev.
- **Services**: Detailed descriptions of services offered, including custom software development and digital marketing.
- **Portfolio**: Showcase of previous work categorized by type (e.g., websites, applications).
- **Blog**: A section for articles and resources related to the industry.
- **Contact**: A page for potential clients to reach out, including social media links and a WhatsApp contact button.
