# Project Summary
**mehmetkuru.dev**, küçük işletmeler, girişimler ve girişimciler için web, e-ticaret, SaaS, mobil uygulama, dijital pazarlama ve DevOps hizmetleri sunan çok dilli bir dijital ajans platformudur. Site; hizmetleri, portföyü, blog içeriklerini ve iletişim kanallarını sergilerken müşteri ve yönetici operasyonlarını tek bir panelde toplar.

Platformda kullanıcı kayıt/giriş akışı, rol bazlı müşteri ve yönetici panelleri, proje takibi, faturalandırma, destek talepleri, dinamik site ayarları ve analitik görünüm bulunur. Google Ads, SEO ve sosyal medya metrikleri veritabanındaki analitik anlık görüntülerinden okunur; canlı dış platform verileri için ilgili API ve OAuth yapılandırmaları gerekir.

Ana sayfanın alt kısmındaki **“Portföy Kategorileri / Projelerimizi Keşfedin”** bölümü ve buna bağlı kayan kategori slider’ı kaldırılmıştır. Ana sayfadaki ayrı **“PORTFÖY — Teslim edilen işler”** vitrini korunmuştur.

# Project Module Description
- **Kimlik Doğrulama ve Roller**: Atoms Cloud Auth ile giriş, kayıt, oturum kapatma ve kullanıcı rolüne göre panel yönlendirmesi.
- **Müşteri Paneli**: Kullanıcının projelerini, aşama/ilerleme durumunu, faturalarını, ödeme durumlarını, destek taleplerini ve profil bilgilerini görüntüler.
- **Yönetici Paneli**: Site ayarları, portföy, blog, müşteriler, faturalar, destek talepleri ve iletişim mesajları yönetilir.
- **Site Ayarları**: Logo, iletişim bilgileri, WhatsApp, sosyal medya bağlantıları, hero metinleri, paket fiyatları, SEO meta bilgileri ve GA4 kimliği backend üzerinden düzenlenir.
- **Portföy Yönetimi**: Proje ekleme, düzenleme, silme, kategori, müşteri, teknoloji, durum ve ilerleme takibi.
- **Blog Yönetimi**: Blog yazıları için CRUD işlemleri, kategori, içerik, kapak görseli, yayın durumu ve slug yönetimi.
- **Faturalandırma**: Yönetici fatura oluşturabilir, güncelleyebilir ve silebilir; müşteriler kendilerine ait faturaları ve durumlarını görür.
- **Destek Talepleri**: Müşteriler talep oluşturur; yöneticiler yanıt verir ve talebi yanıtlandı durumuna getirir.
- **Analitik Dashboard**: Trafik, SEO, Google Ads ve sosyal medya metrikleri kartlar, kanal karşılaştırmaları ve grafiklerle gösterilir. Veriler 60 saniyede bir yenilenir.
- **Dinamik Frontend**: Ana sayfa, hizmetler, iletişim, header, footer ve WhatsApp bağlantısı site ayarlarını kullanır.
- **Blog ve SEO İçerikleri**: SEO makaleleri blog listesine ve statik makale rotalarına entegre edilmiştir; Markdown görünümü ve metadata desteği vardır.
- **Çoklu Dil**: İngilizce, Türkçe ve Almanca arayüz desteği.
- **Performans ve UX**: Lazy loading, Suspense, önbellekleme, responsive paneller ve tema uyumlu bileşenler.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, React Router
- **UI ve Grafikler**: Lucide React, Recharts, Sonner, Markdown-to-JSX
- **State/Data**: TanStack Query, React hooks, localStorage cache
- **Backend**: Python, FastAPI, Atoms Cloud Web SDK
- **Kimlik Doğrulama**: Atoms Cloud Auth
- **Veritabanı**: PostgreSQL
- **Migration**: Alembic
- **Analitik**: GA4 yapılandırması ve backend analitik snapshot modeli
- **Dağıtım**: Cloud hosting altyapısı

# Usage
1. Frontend dizinine geçin:
   ```bash
   cd app/frontend
   ```
2. Bağımlılıkları yükleyin:
   ```bash
   pnpm install
   ```
3. Lint kontrolünü çalıştırın:
   ```bash
   pnpm run lint
   ```
4. Production build alın:
   ```bash
   pnpm run build
   ```
5. Backend bağımlılıklarını kurun:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
6. Backend migration’larını uygulayın ve backend’i proje kurulumundaki sunucu komutuyla başlatın.
7. Frontend geliştirme sunucusunu veya production çıktısını ilgili deployment yapılandırmasına göre çalıştırın.
8. Yönetici erişimi için `site_settings` içindeki `admin_emails` değerine yetkili e-posta adreslerini ekleyin.
9. Canlı Google Ads, Google Search Console veya sosyal medya verileri için gerekli API anahtarları ve OAuth bağlantılarını ayrıca yapılandırın.
10. UI değişikliklerini doğrulamak için lint ve production build komutlarını çalıştırın.
