# Project Summary
**mehmetkuru.dev**, küçük işletmeler, girişimler ve girişimciler için web, e-ticaret, SaaS, mobil uygulama, dijital pazarlama ve DevOps hizmetleri sunan çok dilli bir dijital ajans platformudur. Hizmetleri, portföyü, blog içeriklerini ve iletişim kanallarını sergiler; müşteri ve yönetici operasyonlarını tek panelde birleştirir.

Platformda kimlik doğrulama, rol bazlı müşteri ve yönetici panelleri, proje takibi, faturalandırma, destek talepleri, dinamik site ayarları ve analitik görünüm bulunur. Google Ads, SEO ve sosyal medya verileri backend analitik snapshot’larından okunur.

Site artık Türkçe, İngilizce, Almanca, Arapça, Rusça, Çince ve Hintçe olmak üzere 7 dili destekler. Arapça için RTL düzeni, bayraklı dil seçici, dil bazlı site ayarları ve SEO metadata yönetimi eklenmiştir. Ana sayfanın altındaki portföy kategorileri ve kayan slider kaldırılmış; ayrı portföy vitrini korunmuştur.

# Project Module Description
- **Kimlik Doğrulama ve Roller**: Giriş, kayıt, oturum kapatma ve role göre panel yönlendirmesi.
- **Müşteri Paneli**: Projeler, ilerleme durumu, faturalar, ödemeler, destek talepleri ve profil bilgileri.
- **Yönetici Paneli**: Site ayarları, portföy, blog, müşteriler, faturalar, destek talepleri ve iletişim mesajları.
- **Site Ayarları**: Logo, iletişim bilgileri, sosyal bağlantılar, hero metinleri, fiyatlar, SEO bilgileri ve GA4 kimliği.
- **Dil Bazlı İçerik Yönetimi**: Hero, adres ve SEO alanları her dil için ayrı düzenlenebilir; eksik değerler varsayılan dile düşer.
- **Çoklu Dil ve RTL**: 7 dil, bayraklı dropdown seçici ve Arapça için sağdan sola yerleşim.
- **Portföy Yönetimi**: Proje CRUD işlemleri, kategori, müşteri, teknoloji, durum ve ilerleme takibi.
- **Blog Yönetimi**: Blog CRUD işlemleri, kategori, içerik, kapak görseli, yayın durumu ve slug yönetimi.
- **Faturalandırma**: Yönetici fatura yönetimi; müşterilerin kendi faturalarını görüntülemesi.
- **Destek Talepleri**: Müşteri talepleri, yönetici yanıtları ve durum güncelleme.
- **Analitik Dashboard**: Trafik, SEO, reklam ve sosyal medya metrikleri; 60 saniyelik yenileme.
- **Dinamik Frontend**: Ana sayfa, hizmetler, iletişim, header, footer ve WhatsApp bağlantıları ayarlara bağlıdır.
- **Blog ve SEO**: Veritabanı yazıları ve statik Markdown makaleleri birlikte sunulur.
- **Dil Bazlı SEO**: Meta title, description, Open Graph, Twitter kartları ve hreflang desteği.
- **Performans ve UX**: Lazy loading, Suspense, önbellekleme, responsive paneller ve tema uyumlu bileşenler.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, React Router
- **UI ve Grafikler**: Lucide React, Recharts, Sonner, Markdown-to-JSX
- **State/Data**: TanStack Query, React hooks, localStorage cache
- **Çoklu Dil**: i18next, react-i18next, JSON çeviri kaynakları
- **Backend**: Python, FastAPI, web SDK
- **Kimlik Doğrulama**: Atoms Cloud Auth
- **Veritabanı**: PostgreSQL
- **Migration**: Alembic
- **Analitik**: GA4 yapılandırması ve backend analitik snapshot modeli
- **Dağıtım**: Cloud hosting altyapısı

# Usage
1. Frontend dizinine geçin:
   ```bash
   cd app/frontend
   ```
2. Frontend bağımlılıklarını yükleyin:
   ```bash
   pnpm install
   ```
3. Lint kontrolünü çalıştırın:
   ```bash
   pnpm run lint
   ```
4. Production build alın:
   ```bash
   pnpm run build
   ```
5. Backend bağımlılıklarını kurun:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```
6. Backend migration’larını uygulayın ve backend’i proje kurulumundaki sunucu komutuyla başlatın.
7. Frontend geliştirme sunucusunu veya production çıktısını deployment yapılandırmasına göre çalıştırın.
8. Yönetici erişimi için `site_settings` içindeki `admin_emails` değerine yetkili adresleri ekleyin.
9. Dil bazlı ayarlar için admin panelindeki **Site Ayarları > İçerik Dili** seçicisini kullanın. Çevrilmemiş alanlar varsayılan değeri kullanır.
10. Canlı Google Ads, Search Console veya sosyal medya verileri için ilgili API anahtarları ve OAuth bağlantılarını yapılandırın.
11. Değişiklikleri doğrulamak için lint ve production build komutlarını çalıştırın.
