# Project Summary
**mehmetkuru.dev**, küçük işletmeler, girişimler ve girişimciler için web geliştirme, e-ticaret, SaaS, mobil uygulama, dijital pazarlama ve DevOps hizmetleri sunan çok dilli dijital ajans platformudur. Hizmetleri, paketleri, portföyü, blog içeriklerini, müşteri iletişim kanallarını ve yönetim operasyonlarını tek bir dijital ürün altında birleştirir.

Platform; kullanıcı kimlik doğrulama, rol bazlı müşteri ve yönetici panelleri, proje takibi, faturalandırma, destek talepleri, site ayarları, blog ve portföy yönetimi ile analitik görünüm sağlar. Türkçe, İngilizce, Almanca, Arapça, Rusça, Çince ve Hintçe desteklenir. Arapça için RTL düzeni uygulanır.

Son güncellemelerde cyberpunk çalışma alanı hero görselleri ve preload kaynakları kaldırılmış, yerine görselsiz CSS tabanlı bir hero alanı eklenmiştir. Tüm sabit arayüz metinleri ve dinamik içerik çözümlemeleri yedi dilde i18n yapısına bağlanmıştır. Hafif bir 404 sayfası eklenerek platform tarafından enjekte edilen ağır varsayılan 404 modülü devre dışı bırakılmıştır.

Performans optimizasyonları sonucunda ana JavaScript paketi 659,88 KB’tan 97,89 KB’a, sıkıştırılmış boyutu 32,70 KB’a düşürülmüştür. Ana CSS yaklaşık 73,64 KB, sıkıştırılmış CSS ise 12,34 KB seviyesindedir. Kullanılmayan arayüz bileşenleri temizlenmiş, yönetici, müşteri ve analitik kodları ayrı bundle’lara ayrılmıştır.

# Project Module Description
- **Kimlik Doğrulama ve Roller**: Giriş, kayıt, oturum kapatma ve role göre panel yönlendirmesi.
- **Müşteri Paneli**: Projeler, ilerleme durumu, faturalar, ödemeler, destek talepleri ve profil bilgileri.
- **Yönetici Paneli**: Site ayarları, portföy, blog, müşteriler, faturalar, destek talepleri ve iletişim mesajları.
- **Site Ayarları**: Logo, iletişim bilgileri, sosyal bağlantılar, hero metinleri, paket fiyatları, SEO bilgileri ve GA4 kimliği.
- **Dil Bazlı İçerik Yönetimi**: Hero, iletişim, SEO ve diğer site alanları her dil için ayrı düzenlenebilir.
- **Çoklu Dil ve RTL**: Yedi dil, dinamik çeviri yükleme, HTML `lang`/`dir` güncellemesi ve Arapça RTL desteği.
- **Fallback Çözümleme**: Dinamik portföy, blog, paket ve site ayarı içerikleri seçili dil → Türkçe → varsayılan değer sırasını kullanır.
- **Portföy Yönetimi**: Proje CRUD işlemleri, kategori, müşteri, teknoloji, durum ve ilerleme takibi.
- **Blog Yönetimi**: Blog CRUD işlemleri, kategori, içerik, kapak görseli, yayın durumu ve slug yönetimi.
- **Faturalandırma**: Yönetici fatura yönetimi ve müşterilerin kendi faturalarını görüntülemesi.
- **Destek Talepleri**: Müşteri talepleri, yönetici yanıtları ve durum güncellemeleri.
- **Analitik Dashboard**: Trafik, SEO, reklam ve sosyal medya metrikleri; grafikler analitik bölümü açıldığında yüklenir.
- **Dinamik Frontend**: Ana sayfa, hizmetler, iletişim, header, footer ve WhatsApp bağlantıları ayarlara bağlıdır.
- **404 Yönetimi**: Yedi dilli, hafif ve görselsiz özel sayfa bulunamadı ekranı.
- **Blog ve SEO**: Veritabanı yazıları ile statik Markdown makaleleri birlikte sunulur.
- **SEO ve Yapısal Veri**: Canonical, Open Graph, Twitter kartları, hreflang ve ProfessionalService JSON-LD desteği.
- **Performans Optimizasyonu**: Route bazlı code splitting, vendor ayrıştırma, lazy loading, CSS optimizasyonu ve gereksiz varlık temizliği.
- **Erişilebilirlik ve UX**: Görünür klavye odağı, reduced-motion desteği, alternatif metinler, form etiketleri ve erişilebilir ikon butonları.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, React Router
- **UI ve Grafikler**: Lucide React, Recharts, Sonner, Markdown-to-JSX
- **State/Data**: TanStack Query, React hooks, localStorage cache
- **Çoklu Dil**: i18next, react-i18next, JSON çeviri kaynakları ve dynamic import
- **Backend**: Python, FastAPI ve web SDK
- **Kimlik Doğrulama**: Atoms Cloud Auth
- **Veritabanı**: PostgreSQL
- **Migration**: Alembic
- **Performans**: Route splitting, vendor chunk’ları, lazy loading, CSS optimizasyonu ve gereksiz varlık temizliği
- **Analitik**: GA4 ve backend analitik snapshot modeli
- **SEO**: Canonical, Open Graph, Twitter Cards, hreflang ve JSON-LD
- **Dağıtım**: Cloud hosting ve CDN altyapısı

# Usage
1. Frontend dizinine geçin:
   ```bash
   cd app/frontend
   ```

2. Frontend bağımlılıklarını yükleyin:
   ```bash
   pnpm install
   ```

3. Lint kontrolünü çalıştırın:
   ```bash
   pnpm run lint
   ```

4. Production build alın:
   ```bash
   pnpm run build
   ```

5. Backend bağımlılıklarını kurun:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   ```

6. Backend migration’larını uygulayın ve backend’i proje kurulumundaki sunucu komutuyla başlatın.

7. Frontend geliştirme sunucusunu veya production çıktısını deployment yapılandırmasına göre çalıştırın.

8. Yönetici erişimi için `site_settings` içindeki `admin_emails` değerine yetkili adresleri ekleyin.

9. Dil bazlı içerikleri **Site Ayarları > İçerik Dili** bölümünden düzenleyin.

10. Canlı Google Ads, Search Console veya sosyal medya verileri için ilgili API anahtarlarını ve OAuth bağlantılarını yapılandırın.

11. Yayın öncesinde lint, production build ve arayüz doğrulama kontrollerini çalıştırın.

12. Yayın sonrasında TTFB, CDN, Brotli/Gzip ve cache header değerlerini hosting yapılandırmasında kontrol edin.
