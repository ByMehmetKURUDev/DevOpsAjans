# Project Summary
The project is focused on developing a professional portfolio and agency website, **mehmetkuru.dev**, aimed at showcasing software development and digital marketing services. It provides a modern, engaging platform that highlights the founder's expertise and the agency's offerings, including custom software development, digital marketing, and product design. The site features a visually appealing 3D hero animation, user-friendly navigation, and sections for services, portfolio, blog, and contact, all designed to attract and retain clients. Recently, multi-language support has been added, allowing users to switch between English, Turkish, and German.

# Project Module Description
- **Frontend**: Built with React, featuring a dynamic user interface, routing, state management, and multi-language support.
- **Backend**: Utilizes Atoms Cloud for authentication and database management of projects, blog posts, and inquiries.
- **3D Hero Animation**: Implemented using Three.js to create an interactive visual experience on the homepage.
- **Admin Panel**: Allows for CRUD operations on projects and blog posts, as well as managing inquiries.

# File Description Inventory
- **app/backend/main.py**: Entry point for the backend application.
- **app/backend/core/**: Contains core functionalities like authentication and database connections.
- **app/backend/models/**: Defines data structures for various entities like projects and blog posts.
- **app/backend/routers/**: API endpoints for handling requests related to projects, blog posts, and inquiries.
- **app/backend/services/**: Business logic and interaction with the database.
- **app/frontend/src/**: Contains all frontend source code including components, pages, and styles.
- **app/frontend/public/**: Static assets such as images and the favicon.
- **app/frontend/package.json**: Lists project dependencies for the frontend.

# Technology Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Three.js, i18next
- **Backend**: Python, FastAPI, Atoms Cloud
- **Database**: PostgreSQL
- **Deployment**: Cloud services for hosting

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
2. **Build the Project**:
   - Run the build command:
     ```
     pnpm run build
     ```
3. **Run the Application**:
   - Start the backend server and frontend development server as per the setup instructions in their respective README files.
